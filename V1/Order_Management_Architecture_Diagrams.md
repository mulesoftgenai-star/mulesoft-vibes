## 4. System Integration Patterns

### A. Request-Response Pattern
```
Client → API Gateway → MuleSoft → Backend System → Response → MuleSoft → Client
```

### B. Event-Driven Pattern
```
System Event → Event Queue → MuleSoft Event Processor → Multiple Target Systems
```

### C. Batch Processing Pattern
```
Scheduler → MuleSoft Batch Job → Source System → Transform → Target Systems
```
